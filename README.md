# RadioMix Web

Player + DSP console for RadioMix streams.

**Live:** https://orion292.github.io/RadioMixWeb/

## Features
- Stream player (Icecast/SHOUTcast)
- Web Audio DSP: BaxterEQ, BootEQ, Density, Ferric, epicVerb, AGC, Limiter
- Graphic EQ 31-band + 10-band
- Profiles FM / MTA / WEB
- MTA script generator
